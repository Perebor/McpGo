# McpGo 2.1.1 — исправление первого подключения Playwright Extension

**macOS 14+ / Apple Silicon:** Developer ID signed, Apple-notarized DMG `McpGo-2.1.1-macos-arm64.dmg` и контрольная сумма SHA-256:
https://github.com/mcpgo1/McpGo/releases/tag/v2.1.1

**Windows 11 x64 (experimental):** `2.1.0-preview.3`, неподписанный установщик NSIS и SHA-256:
https://github.com/mcpgo1/McpGo/releases/tag/v2.1.0-preview.3

## Исправлено

- В первом запуске macOS и настройках Windows появилась **прямая кнопка установки официального Playwright Extension из Chrome Web Store**. Chrome/Edge запрашивает разрешения пользователя; скрытой установки расширения нет.
- Пошагово объяснено, как получить `PLAYWRIGHT_MCP_EXTENSION_TOKEN`, вставить его в защищённое поле и подключить браузер. Windows больше не ведёт вместо установки на GitHub-исходники.
- Исправлена ошибка **необъявленной `MODE_FILE`** в ручном скрипте `playwright/configure-extension.sh`; режим Extension и токен теперь записываются с проверками симлинков, корректными правами и временными файлами.
- Обновлена встроенная офлайн-справка: CDP/remote debugging не нужны и больше не рекомендуются. Исправлены публичные инструкции.
- Добавлены тесты интерактивного ввода токена, сохранения настроек, безопасного отказа и кнопок установки для обоих клиентов.

## Обновление

**Mac:** Закройте McpGo, установите новый DMG поверх существующего приложения. Не удаляйте каталог `~/Library/Application Support/McpGo` или записи Keychain: туннели, токены, настройки и задания должны сохраниться. Установленные ранее Chrome Extension и доступные вкладки не меняются обновлением.

**Windows:** Запустите preview.3 от того же пользователя Windows поверх preview.2. Сохранение пользовательских настроек и ключей обеспечивается отдельным зашифрованным хранилищем; установщик остаётся неподписанным и может блокироваться системной политикой. Не отключайте защиту Windows.

**Важно:** официальный браузерный Extension устанавливается в Chrome/Edge только после согласия пользователя. Сам McpGo не добавляет сторонние расширения без разрешения.
