# McpGo 2.1.2 — Playwright workspace ownership и Extension onboarding

**macOS 14+, Apple Silicon:** новый подписанный и нотарифицированный Apple DMG `McpGo-2.1.2-macos-arm64.dmg`, SHA-256 рядом с asset. Ссылка после публикации: https://github.com/mcpgo1/McpGo/releases/tag/v2.1.2.

**Windows 11 x64:** экспериментальный неподписанный NSIS `McpGo.Setup.2.1.0-preview.4.exe`, SHA-256 рядом с asset. Ссылка после публикации: https://github.com/mcpgo1/McpGo/releases/tag/v2.1.0-preview.4.

## Исправлено

- Новым пользователям доступна кнопка установки официального Playwright Extension из Chrome Web Store (Mac/Windows); пошаговая настройка токена в мастере и встроенной справке. Chrome/Edge требует согласия пользователя, расширение не ставится скрыто.
- Устранён аварийный отказ ручного `configure-extension.sh` из-за отсутствовавшей `MODE_FILE`. Токен записывается конфиденциально, с проверками и правами только владельца.
- MCP 2026-07-28: `openai/session` больше не трактуется как стабильная идентичность разговора; `workspace_id` обязателен в схеме браузерных инструментов и повторяется в ответах. При смене сессии владелец остаётся тем же при передаче собственного workspace ID.
- Старый MCP: при переподключении с устойчивым `x-mcpgo-conversation-id` идентичность сохраняется; в других случаях предусмотрено явное безопасное возобновление по `workspace_id`.
- Чужие вкладки по-прежнему защищены, добавлены обезличенные причины отказа и тесты 20 операций и 20 переподключений, параллельных агентов.

## Ограничения

- Когда клиент не передаёт стабильный идентификатор разговора, он должен сохранять и повторно использовать свой `workspace_id`. Автоматически считать два похожих вызова одним агентом небезопасно.
- Полный перезапуск прокси удаляет временную карту вкладок; официальное расширение не гарантирует устойчивый tab ID для автоматического возвращения прежнего владельца. Для неоднозначных вкладок потребуется подтверждение.
- Для Windows установщик остаётся неподписанным; не отключайте системные средства защиты ради установки.

**Обновление:** установите поверх предыдущей версии от того же пользователя, не удаляя пользовательские данные McpGo, Keychain и расширение Chrome. Установленные секреты и туннели хранятся отдельно от приложения.
