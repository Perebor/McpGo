# McpGo 2.1.4 / Windows 2.1.0-preview.6

- Восстановление незавершённого первого подключения без создания дубликатов ресурсов.
- Проверка токена Chrome Extension, восстановление Runtime Key, обработка конфликтов портов и сетевых ошибок.
- Обновлённый «Обзор»: отдельные статусы MCP, туннелей и расширения, история состояния, проверка и переподключение отдельного туннеля.
- Playwright MCP 0.0.86, улучшения производительности и устойчивости браузерных операций.
- Windows: новый интерфейс, улучшения диагностики, экспериментальный неподписанный установщик.

macOS 14+ / Apple Silicon: DMG и SHA-256. Windows 11 x64: Preview EXE и SHA-256 (не подпись издателя). Не отключайте системные средства защиты. Проверка локальных служб не гарантирует доступность инструментов в конкретном чате ChatGPT. Полное тестирование первого подключения на чистых пользовательских компьютерах остаётся необходимым.
